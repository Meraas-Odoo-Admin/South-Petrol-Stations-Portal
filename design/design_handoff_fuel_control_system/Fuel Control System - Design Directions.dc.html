2From scratch — a petrol-tracking visual language: rounded, warm, interactive

نظام التصميم — للتسليم إلى Claude Code

CAIRO · TEAL #0D5C52 · AMBER #E8A53D · RADIUS 10–24PX · SOFT SHADOWS

  • Dropped Modernist entirely — new palette reads as fuel/energy without cliché: a deep petrol teal (#0D5C52) as the working colour, a gauge amber (#E8A53D) as the single accent for primary actions and highlights, warm paper ground (#F7F5EF). Red is reserved only for rule violations (#C1462D) — it never means "brand," only "stop."
  • One typeface, Cairo, for everything — Arabic and Latin share the same geometry so a screen never looks like two systems stitched together. Codes, IDs, plates and DB keys use JetBrains Mono, always inside a bidi isolate.

  • Every field label, status, and message is Arabic. English survives only where it's a literal code: rule identifiers (VEHICLE_GAP_TOO_SHORT), database keys (weekly_fillup_cap), plates and chassis numbers — each now paired with its Arabic meaning right beside it, never standing alone.
  • Interaction: buttons lift on hover, primary actions get a soft amber glow, list rows tint on hover — carried through consistently so a page you build later matches one you saw here.
