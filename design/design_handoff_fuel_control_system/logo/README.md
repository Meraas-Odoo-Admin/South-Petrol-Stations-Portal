# شعار «ضبط الوقود» — الرمز (اتجاه 1a: القراءة الدقيقة)

Pure vector, viewBox 0 0 100 100, no fonts, no gradients. Use as-is on the website and in the card's print file.

| File | Use |
|---|---|
| `dabt-alwaqud-symbol-color.svg` | Default on white/light: teal arc + hub, amber needle |
| `dabt-alwaqud-symbol-white.svg` | On teal — sidebar, card header |
| `dabt-alwaqud-symbol-teal.svg` | One-colour on white |
| `dabt-alwaqud-symbol-black.svg` | Black-only print (#000000) |
| `dabt-alwaqud-app-icon.svg` | Phone home-screen / PWA icon — symbol kept inside the central 60% so circle-cropping launchers don't clip it |
| `dabt-alwaqud-favicon.svg` | Browser tab — symbol on a rounded teal tile |

Colours: teal `#0D5C52`, amber `#E8A53D`, white, black.

- Minimum size: **16 px** on screen, **7 mm** in print (the card header circle, 84 px @ 300 dpi). Below that the needle merges into the hub.
- Clear space: keep at least **the hub's diameter (17% of the symbol)** empty on every side.
- Don't recolour the needle in one-colour versions, rotate the needle, add strokes, shadows or gradients.
